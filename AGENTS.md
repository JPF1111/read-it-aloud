# AGENTS.md

Guidance for AI coding agents working in this repository.

- Read [README.md](README.md), [CONTRIBUTING.md](CONTRIBUTING.md) and [PRIVACY.md](PRIVACY.md) first.
- This repository is the public home of the Read It Aloud docs, site and issue tracker. It does not
  accept code pull requests (see CONTRIBUTING.md); do not open or suggest them.
- Never commit secrets, API keys, tokens or personal data. Describe user data handling only as
  PRIVACY.md does.
- Keep claims in docs consistent with the code's actual behavior; do not invent features.
